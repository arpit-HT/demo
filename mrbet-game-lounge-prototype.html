Prototype notes

Dark sportsbook treatment, Swedish UI copy, English annotations — as agreed. Single committed visual world: the palette is painted explicitly so the page holds on any host background.

Operator names are Swedish-licensed operators used as sample data only; logo marks are placeholder wordmarks pending asset supply (A-01). All figures, tipsters, fixtures and prices are dummy data for structural understanding, not real odds.

Cross-screen state is real: switch Kontostatus and gating, headers and follow states change; settle a tip on T19.6 and the leaderboard, profile and dashboard all move from one calculation. Lapse a licence on T19.1 and every affiliate CTA deactivates.
